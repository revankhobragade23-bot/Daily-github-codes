
# File Integrity Checker

A Python cybersecurity utility that calculates SHA-256
hashes to help verify file integrity.

## Features
- Calculates SHA-256 file hashes
- Reads files in chunks for memory efficiency
- Compares hashes to detect content changes
- Handles missing files and file access errors

## Technologies
- Python
- hashlib
- pathlib
- File handling
- Exception handling

## How to Run
python file_integrity_checker.py

## Learning Outcomes
Learned cryptographic hashing, binary file reading,
and basic file integrity verification.
